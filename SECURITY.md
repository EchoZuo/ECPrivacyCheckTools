# Security Policy

## Scope

ECPrivacyCheckTools handles checks for privacy-sensitive iOS resources and permissions. Security and privacy reports are especially welcome for issues that could cause incorrect permission status handling, unsafe access patterns, unintended disclosure of protected data, or misleading integration guidance.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Instead, report it privately to the maintainer at [zuoqianheng@foxmail.com](mailto:zuoqianheng@foxmail.com), including:

- A clear description of the issue and its potential impact.
- Steps or a minimal example to reproduce it.
- The affected version, iOS version, and Xcode/SDK version when known.

Please allow time for the report to be reviewed before public disclosure. This project currently provides no guaranteed response or remediation timeline.
